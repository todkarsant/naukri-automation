# CV Bank - Resume Files

Place your resume/CV files in this directory.

Supported formats:
- PDF (.pdf)
- DOCX (.docx)
- TXT (.txt)

The automation script will randomly select from available resumes to update your Naukri profile.

## Instructions

1. Upload your different resume versions here
2. Name them clearly (e.g., `resume-backend.pdf`, `resume-fullstack.pdf`, `resume-lead.pdf`)
3. The script will randomly pick one each time it runs
